## 1. 탭 구성과 용어

### 1.1 하단 탭 5개
| 탭 | 성격 | 내용 |
|---|---|---|
| **홈** | 매일 여는 화면 | 오늘 수업, 할 일, 작은 바로가기 [빈자리 보기] [학생 찾기] |
| **브리핑** | 매일 수업 후 | 기존 브리핑 화면 그대로, 우측 상단 [문구 관리] |
| **시간표** | 반과 아이들 | 상단 전환 [시간표] [학생] [대기자] [빈자리] [편성] |
| **달력** | 날짜·월 단위 일 | 상단 전환 [수업 달력] [안내 달력 만들기] |
| **설정** | 가끔 | 공부방 정보, 운영 시간, 교육과정, 공휴일, 할 일 관리, 백업·복원, 로그아웃 |

- 시간표 탭의 [시간표]: 주간 요일×시간 격자가 기본 화면. 반을 누르면 반 상세(명단, 진도, 이번 달 브리핑 현황).
- 달력 탭의 [수업 달력]: 기존 회차 계획 화면. 날짜를 누르면 휴강, 출석 체크, 행사 메모, 토요일은 보강 예약까지. 휴원·행사 등록, 월 확정도 여기서.
- 기존 기능은 위치만 옮기고 동작은 바꾸지 않는다. 기존 URL·바로가기가 있으면 새 위치로 연결.

## 2. 빈자리 현황 (시간표 탭 → [빈자리])

### 2.1 입력 (화면 상단)
- **학년**: 5세~초3 칩 선택. 또는 출생연도 입력 → 기준일 학년으로 자동 변환.
- **기준일**: 날짜 선택 + 빠른 버튼 [오늘] [다음 달 1일] [3월 새 학기](다가오는 3월 1일).
- **데이터 기준**: [실제 시간표] 또는 편성 시안 선택(편집 중인 시안 목록).
- (선택) 희망 요일·시간: 문의하신 분이 원하는 시간이 있으면 그 칸을 강조.

### 2.2 기준일 반영 규칙
- 반: 기준일에 운영 중인 반(개설일 ≤ 기준일, 폐반일 없음 또는 > 기준일).
- 인원: 기준일을 포함하는 배정(예정 배정 포함). 기준일에 퇴원한 학생은 제외, 휴원 중인 학생은 자리를 차지한 것으로 센다.
- 학년: 기준일의 학년도로 계산(3월 전환 반영). 반 학년도 같은 방식.
- 기준일 학년이 초4가 되는 반은 "졸업 대상(운영 여부 확인)"으로 표시하고, 그 시간대를 자동으로 비우지 않는다. 대신 "곧 비는 시간" 목록에 따로 보여준다.
- 시안 기준일 때: 시안의 반·학생을 쓴다. 빼놓은 반·합쳐진 반은 제외, "퇴원 예정" 태그 아이는 빈자리로 계산, "신규"·임시 이름 아이는 인원에 포함.

### 2.3 결과 화면 (위에서 아래로)
**A. 기존 반 빈자리** (선택 학년과 같은 학년)
- "화 4:30 초1반 3/4 · 1자리". 정원 기준은 4명.
- 곧 생길 자리: 기준일 이후 60일 안에 배정 종료·퇴원 예정이 있으면 "3월 15일부터 1자리".
- 바로 위아래 학년 반은 "참고" 영역에 접어서.

**B. 새 반 개설 가능 시간**
- 요일별로, 기준일에 운영 중인 반과 겹치지 않고 앞뒤 간격 10분 이상이며 운영 시간 안에 들어가는 시작 시각.
- 운영 시간: 설정의 요일별 시작·마지막 종료 시각(기본 13:30 ~ 18:30). 수업은 `시작 ≥ 운영 시작`, `시작 + 50분 ≤ 마지막 종료`.
- 기본은 :30 시작만 보여주고, 그 밖의 10분 단위 시각은 "기타 가능 시간"으로 접는다.
- **학년별 선호 시간대**(설정): 기본값 5·6·7세 = 16:00 이후, 초등 = 없음. 선호 시간대에 맞는 시각을 위로 정렬하고 "선호" 표시.
- 학생 2명 이상이면 개설 가능하다는 안내.

**C. 대기자 연결**
- 기존 반 빈자리와 새 반 시각마다, 같은 학년(기준일 기준)이면서 희망 요일·시간이 맞고 희망 시작 시기가 맞는 대기자 수.
  - 희망 시작 시기가 비어 있으면 항상 포함. 있으면 기준일의 달 ±1개월 안일 때 포함.
- 새 반 시각: "대기 1명 · 이번 문의까지 2명이면 개설 가능".
- 숫자를 누르면 해당 대기자 목록.

### 2.4 버튼
- **[대기자로 등록]**: 학년(또는 출생연도), 희망 요일·시간(선택한 칸), 희망 시작 시기(기준일의 달), 문의일(오늘), 단계 "문의"가 채워진 대기자 추가 화면.
- **[체험 예약]**: 선택한 반 또는 시간·학년이 채워진 체험 수업 추가 화면.
- 학부모 안내 문구 복사 기능은 넣지 않는다.

### 2.5 데이터 추가
- `waitlist.wish_start_month text null` ('YYYY-MM', 화면 이름 "희망 시작 시기")
- 설정: 요일별 운영 시간(이미 있으면 재사용), 학년별 선호 시간대.

### 2.6 순수 함수와 테스트 (src/engine/vacancy.ts)
`computeVacancies({ baseDate, grade, source(실제|시안), classes, enrollments, students, waitlist, settings })`
- 화 15:30·16:30·17:30 반이 있을 때 화요일 새 반 시각: 13:30, 14:30(기본), 13:40~14:20(기타). 14:40은 15:30 반과 간격 0분이라 불가.
- 오후 반이 없는 요일, 마지막 종료 18:30일 때 17:40 시작 가능, 17:50 불가.
- 화 16:30 초1반 3명 → 1자리. 4명 → 표시 안 함(곧 생길 자리가 있으면 그쪽에 표시).
- 2026학년도 7세반 + 기준일 2027-03-02 → 초1반으로 계산. 2026학년도 초3반 → 졸업 대상.
- 퇴원일 2027-02-28 학생은 기준일 2027-03-02 인원에서 제외. 시작일 2027-03-02 예정 배정은 오늘 기준에선 제외, 2027-03-02 기준에선 포함.
- 희망 시작 시기 2027-03 대기자: 기준일 2027-02-15 포함, 2026-11-10 제외, 빈칸이면 항상 포함.
- 선호 시간대 16:00 이후 + 7세: 16:30 시각이 13:30보다 위에 정렬.
- 시안 기준: "퇴원 예정" 태그 아이 자리는 빈자리로 계산.

## 3. 홈 화면

### 3.1 구성 (위에서 아래로)
1. **오늘 수업**: 시간 순서로 반 카드. 카드에 반 이름, 출석 확인 표시(✓/미), 브리핑 진행(3/4). 카드의 [출석] [브리핑]을 누르면 해당 화면으로. 수업이 없는 날은 "오늘은 수업이 없습니다 · 다음 수업 ○월 ○일".
2. **오늘 할 일**: 기한이 지났거나 오늘인 할 일. 지난 것은 빨간 표시로 맨 위.
3. **이번 주 할 일**: 이번 주 일요일까지.
4. **다가오는 일**: 14일 이내.
5. 작은 바로가기: [빈자리 보기] [학생 찾기].

### 3.2 출석 확인 표시
- 지금은 결석만 저장하므로 "출석 체크를 했는지" 알 수 없다. 출석 화면 하단에 **[확인 완료]** 버튼을 두고 `attendance_checks(date, class_id, checked_at, checked_by)`에 기록한다. 결석을 하나라도 표시하면 자동으로 확인 완료 처리.

## 4. 할 일

### 4.1 종류
| 종류 | 만들어지는 방식 | 저장 |
|---|---|---|
| 자동 할 일 | 앱 데이터에서 규칙으로 계산 | 계산값. 완료·미루기 상태만 저장 |
| 반복 할 일 | 템플릿(매월·매년·행사 기준)에서 날짜별로 생성 | 템플릿 저장, 발생 건은 계산 + 상태 저장 |
| 직접 추가 | 원장님이 입력 | 저장 |

- 모든 할 일은 고유 키를 가진다. 예: `auto:calendar_export:2027-01`, `tpl:{템플릿id}:2027-02-10`, `manual:{id}`.
- 상태 테이블 `task_states(task_key, status('done'|'snoozed'|'hidden'), snooze_until, memo, done_at, done_by)`.

### 4.2 처리 방식
- **[완료]**: 메모를 남길 수 있다(선택). 반복 할 일은 다음에 같은 할 일이 뜰 때 **"지난번 메모"**(매년 할 일은 작년 메모)가 함께 보인다.
- **[미루기]**: 내일 / 다음 주 월요일.
- **[숨기기]**: 이번 건만 안 보이게(자동 할 일용).
- 자동 해결형 자동 할 일은 조건이 해결되면 저절로 사라진다(완료 처리 필요 없음).
- 두 사람 공용. 담당자 구분 없음. 완료한 사람과 시각은 기록.

### 4.3 자동 할 일 규칙 (설정에서 항목별 켜기/끄기, 기준값 수정)
| 키 | 할 일 | 언제 뜨는지(기본값) | 해결 |
|---|---|---|---|
| calendar_export | 다음 두 달 안내 달력 만들기 | 매월 20일부터, 다음 달이 들어간 안내 달력 내보내기 기록이 없으면 | 자동 |
| month_confirm | 다음 달 수업 달력 확정 | 매월 15일부터, 다음 달 미확정이면 | 자동 |
| progress_missing | 진도 미설정 반 n개 | 이번 달 진도를 계산할 수 없는 운영 중인 반이 있으면 | 자동 |
| attendance_today | 출석 확인 안 한 반 | 오늘 수업이 끝난 반 중 확인 기록이 없으면 | 자동 |
| briefing_today | 브리핑 안 보낸 반 | 오늘 수업이 끝난 반 중 미발송 아이(결석 제외)가 있으면 | 자동 |
| trial_followup | 체험 후 연락: 이름 | 체험 다음 날부터 | 수동 |
| counseling_next | 상담 연락: 이름 | 상담 기록의 다음 연락일부터 | 수동(새 상담 기록이 생기면 자동) |
| waitlist_followup | 대기자 후속 연락: 이름 | 단계가 "문의"·"체험 완료"인 채로 7일 변화 없으면 | 자동(단계 변경 시) 또는 수동 |
| needs_review | 확인 필요 학생 n명 | 해당 학생이 있으면 | 자동 |
| availability_missing | 가능 시간 미입력 n명 | 11~2월에만, 재원생 중 미입력이 있으면 | 자동 |
| leave_return | 휴원 학생 복귀: 이름 | 복귀일 3일 전부터 | 수동 |
| backup | 백업 내보내기 | 매월 1일부터, 이번 달 백업 기록이 없으면 | 자동(백업 시 기록) |
| grade_transition | 새 학년도 반 학년 확인 | 3월 1일~7일 | 수동 |
- 백업 기록: 백업 내보내기를 할 때 마지막 백업 시각을 설정에 저장.
- 규칙 설정 저장: `settings.data.taskRules = { [key]: { enabled, params } }`.

### 4.4 반복 할 일 템플릿
- `task_templates(id, title, description, category('운영'|'행사'|'세무'|'홍보'), recurrence jsonb, lead_days, enabled, sort, memo)`
- recurrence 종류:
  - 매월: `{type:'monthly', day: 1~31 | 'last'}`
  - 매년: `{type:'yearly', month, day}`
  - 행사 기준: `{type:'event', keyword:'페스티벌', offsetDays:-42}` — 행사일 이름에 keyword가 들어간 행사가 있으면 그 날짜 + offset. 없으면 뜨지 않고, 템플릿 목록에 "행사 날짜를 등록하면 표시됩니다" 안내.
- lead_days: 기한 며칠 전부터 "다가오는 일"에 보일지.
- 설정 → 할 일 관리에서 추가·수정·끄기·순서 변경.

|---|---|
| `waitlist.wish_start_month` | 희망 시작 시기 |
| `attendance_checks` | 반별 출석 확인 완료 기록 |
| `task_templates` | 반복 할 일 |
| `tasks` | 직접 추가한 할 일 |
| `task_states` | 모든 할 일의 완료·미루기·숨기기·메모 |
| `settings.data` 추가 | 운영 시간(요일별), 학년별 선호 시간대, taskRules, lastBackupAt |
- 새 테이블 모두 RLS + `private.is_member()` 정책. 백업 내보내기에 포함.

## 6. 순수 함수 (src/engine/tasks/)
- `buildAutoTasks(today, data, rules)` → 자동 할 일 목록
- `expandTemplates(templates, events, range)` → 기간 안의 반복 할 일 발생 목록
- `bucketize(tasks, states, today)` → 오늘/이번 주/다가오는 일, 지난 할 일 표시
- 테스트 예:
  - 11월 19일엔 calendar_export 없음, 20일엔 있음, 12·1월 안내 달력을 내보내면 사라짐
  - 매월 'last' → 2027-02는 28일
  - 행사 "2027 페스티벌" 2027-09-26 + offset −42 → 2027-08-15, lead 7 → 08-08부터 표시
  - 미루기 '다음 주' → 다음 월요일까지 숨김
  - 작년 메모: 2026-02-10 사업장현황신고 완료 메모가 2027-02-10 건에 표시
  - availability_missing은 3~10월에 뜨지 않음

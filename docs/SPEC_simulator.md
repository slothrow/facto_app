# 학사운영 앱 상세 기획서 (4단계: 반 편성 시뮬레이터)

> 앞 문서: SPEC.md(회차 엔진), SPEC_students.md(반·학생), SPEC_briefing.md(진도·브리핑).
> 이번 범위: 현재 시간표를 복사한 "시안"에서 반을 옮기고·만들고·빼고·합쳐 보며 검토하고, 고른 시안을 실제 반에 적용.
> 범위 밖(나중): 아이 한 명씩 다른 반으로 옮기기, 시안 이미지 저장, 학부모 변경 안내 문구.

## 1. 목표와 사용 장면
- 새 학기·월 전환 전에 종이에 시간표를 적고 동그라미·화살표·X로 고민하던 작업을 앱으로 옮긴다.
- 예: 7세반(예비 초1)을 화 4:30 → 2:30으로 옮겨 보기, 신규 상담으로 들어올 예비 5세반을 만들어 배치해 보기, 졸업할 초3반을 빼 보기.
- **시안에서 무엇을 해도 실제 반·학생 데이터는 바뀌지 않는다.** [적용하기]를 눌렀을 때만 반영된다.

## 2. 시안(draft)

### 2.1 만들기
- [새 시안] → 원본 선택: "현재 시간표" 또는 "다른 시안 복제".
- 현재 시간표에서 만들 때 **기준일**(기본: 오늘)을 정한다. 그날 운영 중인 반과 그날 배정된 학생을 복사한다.
- 복사하는 것: 반(요일, 시작 시간, 학년, 별칭, 메모, 진도), 반별 학생 목록.
- 복사하지 않는 것: 학생 정보 자체(이름, 가능 시간 등은 항상 실제 학생 데이터를 읽는다).

### 2.2 시안 목록
- 이름(예: "2027 새학기 A안"), 기준일, 마지막 수정, 요약(5장), 상태(편집 중 / 적용됨 / 보관).
- 이름 바꾸기, 복제, 보관, 삭제(확인 후).
- **두 시안 비교**: 요약 숫자와 변경 건수를 나란히(5.3).

### 2.3 저장과 되돌리기
- 모든 조작은 즉시 자동 저장한다.
- **되돌리기 / 다시 실행**: 이번 접속 중 조작 기록(최대 50개). 화면 상단 버튼.
- [처음으로]: 시안을 만들었을 때 상태로 초기화(확인 후).
- 두 사람이 같은 시안을 동시에 고치는 경우는 고려하지 않는다(나중 저장이 이김).

## 3. 시안 화면

### 3.1 시간표 격자
- 열: 운영 요일(월~금). 행: 10분 단위, 운영 시간대(설정, 기본 13:30~18:30) 전후 여유 포함.
- 반 블록 높이 = 50분. 시작 시간이 정시가 아닌 반(예: 3:40)도 정확한 위치에 표시.
- **학년 보기 전환**: [현재 학년도] / [다음 학년도]. 다음 학년도 보기에서는 모든 학년이 한 단계 올라간다(7세 → "초1(예비)"). 초4가 되는 반에는 "졸업 대상" 배지.
- 폰 세로 화면: 요일 탭 전환(한 요일씩) + 가로로 돌리면 전체 격자. PC·태블릿: 전체 격자.

### 3.2 반 블록 표시
- 학년, 시작 시간, 별칭, 인원(예: 3/4), 진도(예: P9), 경고 아이콘, 메모 아이콘, 맞는 대기자 수 배지(예: "대기 2").
- PC: 블록 안에 아이 이름 + 태그 색. 폰: 인원만, 탭하면 펼침.
- **옮긴 반**: 원래 자리에 점선 테두리 흔적과 "→ 화 2:30" 표시.
- 새로 만든 반: "신규" 배지.

### 3.3 빼놓은 반 영역
- PC는 격자 오른쪽, 폰은 화면 아래 접이식 영역.
- 반을 이곳에 놓으면 시간표에서 빠진다(삭제 아님). 다시 격자로 옮기면 복귀.
- 적용 시 빼놓은 반은 폐반 처리(6장).

## 4. 반 옮기기 조작

### 4.1 놓을 수 있는지 판단 (순수 함수, 기존 겹침 검사 재사용)
- 같은 요일 다른 반과 `[시작, 시작+50분)`이 겹치면 **불가**(회색).
- 앞뒤 반과 간격 10분 미만이면 **경고**(노랑, 놓을 수는 있음).
- 운영 시간대 밖이면 **경고**.
- 시작 시간은 10분 단위로 맞춘다.

### 4.2 탭 방식 (폰 기본, PC에서도 동작)
1. 반을 탭 → 선택 상태(진한 테두리), 하단 안내 "옮길 위치를 누르세요" + [빼놓기] [취소] 버튼.
2. 격자에서 놓을 수 있는 시작 칸은 초록, 경고 칸은 노랑, 불가 칸은 회색으로 표시.
3. 칸을 탭 → 이동. 다른 반 블록을 탭 → "이 반으로 합치기" 확인(4.4).
4. 선택한 채로 요일 탭을 바꾸거나 스크롤해도 선택이 유지된다(다른 요일로 옮길 때).
5. 같은 반을 다시 탭하거나 빈 곳·[취소]를 누르면 선택 해제.

### 4.3 드래그 방식
- 라이브러리: dnd-kit(마우스·터치 동시 지원) 권장.
- PC: 마우스로 누른 채 5px 이상 움직이면 끌기 시작.
- 폰: **0.25초 길게 누르면** 반이 들리고 짧게 진동(`navigator.vibrate`), 그 상태로 끌기. 짧게 쓸면 일반 스크롤.
- 끄는 동안 4.1 색 표시, 화면 가장자리에서 자동 스크롤, 10분 칸에 맞춰 붙기.
- 놓는 곳: 격자 칸(이동), 다른 반 블록(합치기 확인), 빼놓은 반 영역(빼기).
- 불가 칸에 놓으면 원래 자리로 돌아간다.

### 4.4 반 합치기
- 반 A를 반 B에 놓으면 확인창: "A반 학생 n명을 B반으로 합칠까요?" + 합친 뒤 인원, 경고(정원, 학년 차이, **진도 차이**).
- 진도 차이: 두 반의 다음 수업월 단계·단원이 다르면 "진도 차이 2단원(P9 / P7)" 표시. 합친 반은 B반 진도를 따른다.
- 합치면 A반은 시안에서 사라지고(변경 목록에 "A반 → B반 합침"), 되돌리기 가능.

### 4.5 새 반 만들기
- 빈 칸을 탭(탭 방식)하거나 [+ 새 반] → 요일·시간·학년·별칭·메모·시작 진도 입력.
- 학년은 지금 보고 있는 학년 보기 기준으로 입력하고, 저장할 때 기준 학년도와 함께 기록한다.
- 시작 진도 기본값: 학년의 기본 단계 1단원(예: 5세 → 베이직 1단원). 적용할 수업월부터 시작.
- 학생이 없는 반도 만들 수 있다.

## 5. 반 상세(시안 안에서)
- 반 블록을 길게 누르거나(폰) 더블클릭(PC), 또는 선택 상태에서 [상세] → 바텀시트/옆 패널.

### 5.1 아이 목록과 상태 태그
- 태그: **유지**(기본) / **이동**(파랑) / **퇴원 예정**(회색·취소선) / **신규**(초록) / **미정 ??**(노랑).
- 태그를 탭해서 바꾼다. 아이마다 짧은 메모 가능.
- 아이 추가: [+ 대기자에서] (아래 5.2), [+ 임시 이름](아직 대기자 등록 전인 상담 아이. 적용할 때는 반영되지 않고 안내만 한다).
- 기존 재원생을 다른 반으로 옮기는 기능은 이번 범위 밖.

### 5.2 대기자 연결
- 반 상세에 "맞는 대기자" 목록: 학년(학년 보기 기준)과 희망 요일·시간이 맞는 대기자. 탭하면 이 반에 "신규" 태그로 추가.
- 반 블록 배지 "대기 N".
- 탭 방식으로 반을 선택했을 때, 대기자 희망 시간에 맞는 칸에는 작은 "대기 N" 점 표시.

### 5.3 반 메모
- 반마다 고민 메모(예: "?? 4명 채울 수 있을지"). 블록에 메모 아이콘.

### 5.4 진도
- 기존 반: 실제 반의 진도를 그대로 따라간다(옮겨도 유지).
- 새 반: 시작 단계·단원 수정 가능.

## 6. 검토 기능

### 6.1 경고 패널 (항상 계산, 막지는 않음 — 겹침만 막음)
- 정원 초과(5명 이상), 6명 이상은 저장 불가.
- 인원 2명 미만(학생 없는 신규 반은 "학생 없음"으로 따로 표시).
- 아이 학년과 반 학년 불일치(학년 보기 기준).
- **가능 시간 충돌**: 반에 속한 아이의 "가능 요일·시간"과 반 요일·시작 시간이 맞지 않으면 "이 시간 안 되는 아이 2명: 이름, 이름". 가능 시간이 비어 있는 아이는 "가능 시간 미입력 n명"으로 따로 안내.
- 간격 10분 미만, 운영 시간대 밖.
- 진도 차이(합친 반).
- 경고를 누르면 해당 반으로 이동·선택.

### 6.2 변경 목록 (원본 대비 자동 계산)
- 이동: "7세반 화 4:30 → 화 2:30"
- 신규: "예비 5세반 신규 (월 1:30)"
- 빼놓음: "초3반 빼놓음 (목 5:30)"
- 합침: "초2 A반 → 초2 B반 합침"
- 학년·별칭 변경, 아이 태그 변경(퇴원 예정 n명, 신규 n명).
- 항목을 누르면 해당 반 선택.

### 6.3 시안 요약
- 반 수, 학생 수(퇴원 예정 제외, 신규 포함), 빈자리 합계(정원 4 기준), 학년별 반 수, 경고 수.
- 시안 화면 상단 한 줄 + 시안 목록에 표시. 두 시안 비교 화면에서 나란히.

## 7. 적용하기

### 7.1 적용 시점
- **수업월 기준(기본)**: 적용할 수업월(예: 2027-03)을 고르면, 반마다 그 요일의 "그 수업월 1주" 날짜부터 바뀐다(교육비·진도 단위가 깔끔). 요일마다 날짜가 다를 수 있으니 미리보기에 반별 적용일을 보여준다.
- **날짜 기준**: 날짜 하나를 고르면 모든 변경이 그날부터.

### 7.2 미리보기 (적용 계획은 순수 함수로 계산 → 테스트)
- 실행될 작업 목록:
  - 옮긴 반: 기존 반 폐반(적용일 전날) + 새 반 개설(적용일) + 학생 배정 이동 + 진도 이어받기(새 반 기준점 = 기존 반의 그 수업월 단계·단원). 과거 출석·브리핑 기록 보존을 위해 기존 반을 고치지 않고 새로 만든다.
  - 새 반: 개설 + 시작 진도 기준점.
  - 빼놓은 반: 폐반 + 소속 학생 배정 종료(남은 학생이 있으면 경고).
  - 합친 반: A반 폐반 + 학생을 B반으로 배정.
  - 학년·별칭 변경: 반 정보 수정.
  - 퇴원 예정 아이: 퇴원 처리(아이별 체크, 기본 체크).
  - 신규 태그 대기자: 학생으로 등록 + 배정(아이별 체크, 기본 체크), 대기자 단계 "등록".
  - 임시 이름: 반영 안 함(목록에 안내만).
- **시안을 만든 뒤 실제 데이터가 바뀐 경우**(배정 추가·퇴원·반 변경 등) "시안 만든 뒤 바뀐 내용 n건"을 먼저 보여주고 계속할지 확인.
- 적용 전 "백업 내보내기를 먼저 하세요" 안내와 [백업 내보내기] 버튼.

### 7.3 실행
- 한 번에 전부 성공하거나 전부 취소되도록 DB 함수(RPC) 하나에서 트랜잭션으로 처리한다. 함수는 `security invoker`로 만들어 기존 RLS(`private.is_member()`)가 그대로 적용되게 한다.
- 성공하면 시안 상태 "적용됨", 적용 시각·적용 결과 요약 저장. 적용된 시안은 읽기 전용.

## 8. 데이터 모델 추가
| 테이블 | 주요 컬럼 |

| `sim_drafts` | id, name, base_date, source_draft_id null, status('editing' \| 'applied' \| 'archived'), grade_view('current' \| 'next'), memo, applied_at, applied_summary jsonb, created_at, updated_at, updated_by |
| `sim_classes` | id, draft_id, source_class_id null(신규면 null), weekday, start_time, grade_code, grade_basis_year, alias, memo, removed bool, merged_into null, start_stage, start_unit(신규 반 시작 진도) |
| `sim_members` | id, draft_id, sim_class_id, student_id null, waitlist_id null, temp_name null, tag('keep' \| 'move' \| 'leaving' \| 'new' \| 'undecided'), memo |
| `settings` 추가 | 운영 시간대(요일별 시작·끝, 기본 13:30~18:30) |
- 새 테이블 모두 RLS + `private.is_member()` 정책. 백업 내보내기에 포함.
- 원본 비교용으로 시안을 만들 때의 반·배정 상태를 `sim_drafts.base_snapshot jsonb`에 함께 저장해도 된다(변경 목록·"바뀐 내용" 검사에 사용).

## 9. 순수 함수와 테스트 (src/engine/simulator/)
- `canPlace(draft, classId, weekday, start)` → ok / warn(사유) / block(사유)
- `diffDraft(baseSnapshot, draft)` → 변경 목록
- `checkDraft(draft, students, waitlist, settings)` → 경고 목록(가능 시간 충돌 포함)
- `summarize(draft)` → 요약
- `planApply(draft, real, option)` → 실행 작업 목록(미리보기용)
- 테스트 예:
  - 화 16:30 반을 화 14:30으로 → ok, 14:30 칸에 다른 반이 있으면 block
  - 15:30 반이 있는 요일에 16:20 시작 → warn(간격 0분), 16:10 → block
  - 가능 시간 "화 15:00 이후"인 아이가 있는 반을 화 14:30으로 → 충돌 1명
  - 다음 학년도 보기에서 2026학년도 7세반 → 초1, 초3반 → 졸업 대상
  - 수업월 기준 적용: 수요일 반의 2027-03 수업월 1주 날짜가 회차 엔진 결과와 같은지
  - 옮긴 반의 새 진도 기준점 = 기존 반의 적용 수업월 단계·단원

## 10. 화면 진입
- 반·학생 탭 상단 전환에 [편성] 추가: [반] [학생] [대기자] [편성].
- 편성 → 시안 목록 → 시안 화면.

## 11. 확인 필요 사항 (기본값으로 진행, 다르면 수정)
- 적용 시점 기본값은 수업월 기준. 새 학기처럼 모든 요일을 같은 날 바꾸고 싶으면 날짜 기준 선택.
- 초3반은 다음 학년도 보기에서 "졸업 대상"으로 표시(교육과정이 S단계=초3까지이므로).
- 운영 시간대 기본 13:30~18:30, 밖에 놓는 건 경고만.
- 임시 이름 아이는 적용 때 반영하지 않음(대기자로 먼저 등록해야 학생이 됨).

## 12. 결정된 내용 (2026-11-08)
- 적용 시 아이 태그 **이동·미정**은 표시만 한다(유지처럼 그 반에 그대로). 미리보기에 "적용 후 직접 확인" 안내.
- 옮긴 반을 적용하면 **적용일 이후** 기존 반의 베이직 수업 계획·체험수업 예약은 새 반으로 옮긴다(요일이 같을 때. 요일이 바뀌면 날짜가 맞지 않아 기존 반에 남기고 안내). 적용일 전 기록(출석·브리핑 등)은 기존 반에 그대로.
- 날짜 표기: 폐반일(closedOn) = 그날부터 수업 없음 = 적용일, 배정 끝 = 적용일 전날(기존 반·배정 데이터와 같은 뜻).
- 배정 이동은 이전 반 배정을 (새 반 시작일, 이전 반 폐반일) 중 빠른 날 전날까지로 끝낸다(요일이 바뀌어도 두 반에 동시에 걸리지 않게).
- 운영 시간대는 settings 안(`operatingHours`)에 요일별로 저장(교육과정 설정과 같은 방식, 새 테이블 없음).
- 탭 방식·드래그 방식·새 반 만들기는 모두 `canPlace` 하나로 판단한다(기존 `checkClassTime` 겹침·간격 검사 재사용).
- 적용 실행: 앱이 `planApply`로 계산한 변경(추가·수정할 행, 지울 배정)을 DB 함수 `apply_sim_draft(시안 id, 변경)` 하나가 한 트랜잭션으로 실행(security invoker → RLS 그대로). 시안을 잠그고 '편집 중'일 때만 실행해 두 번 적용을 막는다.
- 적용 후 시간표: 반·학생 탭 시간표에 "시간표 바뀜: [지금] [3/2부터]…" 날짜 칩. 날짜를 고르면 그날 운영하는 반·명단. [지금]에서는 지금 반과 시간이 겹치는 개설 예정 반(옮겨 갈 반)을 숨긴다.
- 적용된·보관한 시안은 읽기 전용(되돌리기 단축키도 막음).

# 원장님 안내 (5단계: 홈 할 일, 빈자리)

## 홈 할 일 쓰는 법
1. 앱을 열면 **홈**: 맨 위 오늘 수업 카드에서 [출석]·[브리핑]으로 바로 가요.
2. 수업이 끝나면 출석 화면 맨 아래 **[확인 완료]**(결석을 누르면 저절로 완료).
3. **오늘 할 일**의 빨간 날짜는 지난 일. 누르면 [바로 가기]·[완료]·[미루기].
4. 완료할 때 남긴 **메모**는 다음 달·내년 같은 할 일에 "지난번 메모"로 보여요.
5. 내 할 일은 [+ 추가]. 반복 할 일·자동 할 일은 설정 → 할 일 관리에서 켜고 끄기.

## 빈자리 보는 법
1. 시간표 탭 → **[빈자리]** (홈 바로가기 [빈자리 보기]도 같아요).
2. 학년 칩을 누르거나 [출생연도로 입력], 기준일은 [오늘]·[3월 새 학기].
3. **A** 기존 반 남은 자리(곧 생길 자리 날짜), **B** 새 반을 열 수 있는 시간.
4. "대기 n명"을 누르면 그 시간에 맞는 대기자 목록.
5. 원하는 칸을 누르고 아래 **[대기자로 등록]** 또는 **[체험 예약]**.

## 5단계 점검 결과 (2026-11-10)
- 새 표(출석 확인·할 일·할 일 상태·반복 할 일)와 대기자 희망 시작 시기: 백업 내보내기·복원에 포함. 예전 백업을 복원해도 지금 할 일·반복 할 일은 남는다(테스트).
- 로그아웃 상태(anon 키) 요청: 새 표 모두 "permission denied". RLS 켜짐 + "members only" 정책 1개씩.
- Security Advisor: 새 경고 없음(기존 유료 기능 leaked password protection 1개만).
- 첫 로딩: 화면 코드 한 덩어리 864KB(gzip 245KB) → 안내 달력 만들기(이미지 도구)·편성(드래그 도구)을 열 때 불러오게 나눠 692KB(gzip 192KB). 홈의 "다음 수업일" 찾기를 60번 계산 → 1번으로.
- 남은 개선안: 로그인 직후 학생 데이터 표 21개를 한꺼번에 전부 읽는다(브리핑 기록·결석·할 일 상태가 해마다 늘어남). 느려지면 브리핑 기록·결석은 최근 1년만 먼저 읽고 나머지는 학생 카드에서 필요할 때 읽게 바꾼다.

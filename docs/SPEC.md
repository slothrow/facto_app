# 학사운영 앱 상세 기획서 (1단계: 회차 계획 + 안내 달력)

## 1. 배경과 현재 방식
- 원장은 매달 공휴일·휴원일을 확인하면서 요일별로 "몇 월 몇 주차 수업을 어느 날 할지"를 종이에 적어 가며 정해 왔다.
- 확정되면 PPT로 두 달치 달력을 편집하고, 캡처해서 학부모에게 카카오톡 등으로 보낸다.
- 손으로 하다 보니 오기가 생긴다. 예: 2026년 12/21(월)이 "3주"로 적혀 있지만 규칙상 "4주"(색은 4주 색으로 칠해져 있음).
- 이 앱의 목적:
  1. 회차 초안을 자동으로 만들고, 밀고 당기는 조정을 쉽게 하고, 요일별 진도 차이를 한눈에 보여준다.
  2. 이 달력으로 여름·겨울 휴가(휴원) 일정을 언제 넣을지 검토한다.
  3. 확정한 결과로 배포용 두 달 달력 이미지를 바로 만든다.

## 2. 운영 사실 (현재 기준)
- 대상: 5·6·7세 미취학 아동, 초1~3학년. 반은 같은 나이/학년으로 구성.
- 정원: 반당 최소 2명, 최대 4명. 같은 주차 진도 반에 보강 학생이 들어가면 5명까지.
- 수업: 월~금, 대략 13:30~18:30 사이. 50분 수업 + 10분 교체. 단, 2:20, 5:40처럼 정시 격자에 맞지 않는 반도 있다(반 편성 기능 때 반영).
- 반은 요일·시간이 고정. 같은 요일·같은 시간에 수업월당 4회.
- 1단계 가정: **같은 요일의 반들은 모두 같은 회차 일정으로 움직인다** (요일반 단위).
- 보강: 결석 시 같은 주차 진도 수업이 있으면 그 타임에 참여. 그 외에는 토요 보강데이(30분 단위). 당일 결석 보강 불가, 보강은 월 1회 제한.
- 교육비: 수업월(4회 묶음) 단위. 월말 일괄 발송, 수업월 첫 주까지 마감.

## 3. 회차 배치 규칙 (스케줄 엔진)

### 3.1 기본 원리: 요일반별 롤링
- 요일반마다 "시작점(anchor)"이 있다: `{ date, courseMonth, weekNo }`. 예: 월요일 = 2026-11-02, 2026-11, 1주.
- 시작점부터 7일 간격으로 그 요일의 날짜를 순서대로 본다.
  - 공휴일 → 휴강, 회차 소비 안 함
  - 휴원일(해당 요일에 적용되는 것) → 휴강, 회차 소비 안 함
  - 비우기(skip) → 휴강, 회차 소비 안 함
  - 고정(pin) 또는 확정 스냅샷에 있는 날짜 → 지정된 회차를 쓰고, 그다음부터는 그 회차 기준으로 이어 감
  - 그 외 → 현재 회차를 배정하고 다음 회차로 진행
- 다음 회차: 주차 1→2→3→4, 4 다음은 다음 수업월의 1주.
- 결과적으로 달력월에 그 요일이 5번 있으면 다음 수업월 1주가 당겨지고, 공휴일이 끼면 뒤로 밀린다. 원장의 실제 운영 방식("밀리거나, 앞 달에 비어 있으면 당긴다", "5회인 달로 맞춘다")과 같다.
- 공휴일에는 고정할 수 없다. 공휴일에 수업하려면 설정에서 해당 공휴일을 "무시"로 바꾼다.
- 휴원일에도 고정할 수 없다(휴원일 우선).
- 날짜 판정 우선순위: 확정 스냅샷 > 공휴일(무시 안 된 것) > 휴원일 > 비우기 > 고정 > 일반.
  - 확정된 날짜에 나중에 공휴일·휴원일이 겹쳐도 확정 회차를 유지하고 "확정과 어긋남" 경고만 낸다.
- 확정된 달 안의 날짜에는 비우기·고정을 할 수 없다(확정 해제 후 수정). 엔진은 이런 입력이 들어오면 무시하고 확정값을 쓴다.
- 비활성 요일반(운영 요일에서 끈 요일)은 회차를 만들지 않고, 그 요일 칸은 `none`.
- 시작점 이전 날짜는 `none`. 엔진은 `range.from`과 무관하게 항상 시작점부터 계산한다(범위 밖 결과는 출력에서 잘라냄). offset 계산을 위해 `range.to` 이후의 다음 회차도 내부적으로 구한다.

### 3.2 엔진 입력과 출력
```ts
type WeekNo = 1 | 2 | 3 | 4;
type SessionLabel = { courseMonth: string; weekNo: WeekNo }; // courseMonth 'YYYY-MM'

interface ScheduleInput {
  range: { from: string; to: string };            // 'YYYY-MM-DD'
  tracks: { weekday: 1|2|3|4|5; active: boolean; anchor: { date: string } & SessionLabel }[];
  holidays: { date: string; name: string }[];      // 내장 + 수동 추가
  ignoredHolidays: string[];                        // 무시할 공휴일 날짜
  closures: { from: string; to: string; label: string; weekdays?: number[] }[]; // weekdays 없으면 전체
  events: { date: string; label: string; showOnCalendar: boolean }[];
  overrides: ({ date: string; type: 'skip' } | ({ date: string; type: 'pin' } & SessionLabel))[];
  confirmedSessions: ({ date: string } & SessionLabel)[]; // 확정된 달의 스냅샷 = 고정으로 취급
  makeupOverrides: { date: string; type: 'add' | 'remove' }[];
}

interface DayCell {
  date: string;
  weekday: 0..6;
  status: 'session' | 'holiday' | 'closed' | 'skipped' | 'makeup' | 'none';
  session?: SessionLabel & { pinned: boolean; confirmed: boolean };
  holidayName?: string; closureLabel?: string; events: string[];
}

interface ScheduleOutput {
  days: DayCell[];
  monthSummaries: MonthSummary[]; // 3.3
  warnings: Warning[];            // 3.4
}
```
- 엔진은 순수 함수. 입력만으로 결과가 결정된다. DB에는 입력(시작점, 휴원, 비우기/고정, 확정 스냅샷 등)만 저장하고, 회차 결과는 매번 계산한다.

### 3.3 달력월 요약과 앞섬/밀림(offset)
- 달력월 X, 요일반별로:
  - 이번 달 회차 수와 내역. 예: "월 5회: 11월 1~4주, 12월 1주"
  - 월말 offset: 달력월 X가 끝난 뒤 그 요일반의 다음 회차가 (M월, w주)라면
    `offset = (monthIndex(M) - monthIndex(X+1)) * 4 + (w - 1)`
    - 양수 = 그만큼 앞섬(당겨짐), 음수 = 밀림, 0 = 정상(다음 달 1주부터 시작)
- UI 표시: "+2 (2회 앞섬)", "−1 (1회 밀림)", "정상".
- 이 값이 원장이 휴원(방학) 시점을 정하는 판단 근거가 된다.

### 3.4 경고(막지는 않고 알려만 줌)
- 회차 누락: 고정/확정 때문에 어떤 회차가 건너뛰어진 경우(같은 요일반에서 회차가 앞으로 건너뜀). 예: "월요일: 1월 1주 누락"
- 회차 중복: 같은 요일반 안에서 같은 회차가 두 번 배정된 경우(회차가 뒤로 돌아감)
- 앞섬/밀림이 기준치 이상: `|offset| ≥ 기준치`(설정값, 기본 2회). 앞섬·밀림 양쪽에 적용. 시드 데이터에서도 12~2월 화·수·목에 경고가 뜨는 것은 의도된 동작.
- 확정된 달이 상류 변경 때문에 원래 계산과 달라진 경우: "확정된 1월과 연결이 맞지 않습니다"
  - 판정: 확정된 달의 첫 회차가, 그 직전까지 계산된 결과에서 이어지는 다음 회차와 다르면 경고. 확정된 날짜에 공휴일·휴원일이 겹친 경우도 이 경고.
  - 누락/중복 경고와 함께 뜰 수 있다(예: 시나리오 C는 "월요일: 1월 1주 누락" + "확정된 1월과 연결이 맞지 않습니다" 둘 다).

### 3.5 보강데이
- 자동 제안: 달력월마다 마지막 토요일. 그날이 공휴일·휴원일이면 그 전 토요일, 그것도 안 되면 계속 앞 토요일로. 그 달에 가능한 토요일이 없으면 보강데이 없음.
- 원장이 다른 토요일로 바꾸거나, 추가하거나, 없앨 수 있다(makeupOverrides).
  - 같은 달에 `add`가 하나라도 있으면 그 달의 자동 제안은 숨긴다(= "다른 토요일로 바꾸기"). 월 2회가 필요하면 `add`를 두 개 둔다.
  - `remove`는 자동 제안 또는 `add`된 날을 없앤다.
- 실제 사례: 2026-11은 11/28(자동 제안과 같음), 2026-12는 12/19(수동 지정, 자동 제안은 12/26).

### 3.6 확정
- 달력월 단위로 "초안" / "확정" 상태.
- 확정 시 그 달의 회차 결과를 스냅샷으로 저장 → 이후 고정으로 취급.
- 확정 해제는 확인 대화상자를 거친다.
- 앞 달을 수정해서 확정된 달과 연결이 어긋나면 경고(3.4)를 보여주고, 확정본은 자동으로 바꾸지 않는다.

## 4. 휴원일과 행사일
- 휴원일: 기간(from~to), 이름(예: 겨울방학), 적용 요일(선택, 없으면 전체). 해당 날짜는 휴강.
- 행사일: 날짜, 이름, 달력 이미지에 표시 여부. 수업에 영향 없음.
  - 예: 2026-11-14(토) "2026 수원 플레이팩토 보드게임 페스티벌"
- 임시공휴일: 공휴일 목록에 수동 추가.

- E. 고정: 금 2027-01-08을 `1-1`로 고정 → 1/15 `1-2` … 그리고 경고 "금요일: 12월 4주 누락".

## 8. 화면 설계
하단 탭 3개로 시작: **회차 계획 / 달력 만들기 / 설정**. 탭 추가가 쉬운 구조로 만든다(라우트 + 탭 설정 배열).

### 8.1 회차 계획
- 상단: `< 2027년 1월 >` 월 이동, 상태 배지(초안/확정).
- 월 달력(일~토 7열):
  - 평일 칸: 날짜 + 주차 색 띠와 라벨(같은 수업월이면 "2주", 다른 수업월이면 "2월 1주").
  - 공휴일: 이름 표시(빨강), 휴원: 이름 표시(회색), 비운 날: "비움"(회색 빗금).
  - 고정된 회차: 작은 핀 아이콘. 확정된 달: 자물쇠 아이콘.
  - 토요일: 보강데이면 "보강수업" 띠.
  - 행사: 작은 점 + 이름.
- 칸 탭 → 바텀시트:
  - 평일: [이 날 비우기(이후 회차 뒤로)] / [비우기 취소(다시 당기기)] / [회차 직접 지정] / [고정 해제] / [행사 메모]
  - 토요일: [보강데이 지정/해제] / [행사 메모]
  - 적용 전에 영향 미리보기: "이후 월요일 7회가 1회씩 밀립니다"
- 하단 요약 카드(요일별 한 줄): "월 4회 · 1월 2~4주, 2월 1주 · 월말 +1"
- 경고 목록(있을 때만).
- 버튼: [휴원 기간 추가], [이 달 확정] / [확정 해제].

### 8.2 달력 만들기
- 시작 월 선택(두 달 묶음). 기본값은 아직 내보내지 않은 다음 두 달.
- 두 달 중 초안 상태인 달이 있으면 "아직 확정되지 않은 달이 있습니다" 안내(막지는 않음).
- 입력:
  - 제목(기본: "1월, 2월 수업 안내")
  - 강조 안내 문구(여러 줄, 이번 회차 공지: 행사, 시간표 조정 등)
  - 기본 안내 문구(설정의 템플릿을 불러오고, 여기서 이번만 수정 가능)
  - 행사 표시 여부(해당 기간 행사 목록에서 체크)
  - 비율: 1:1(기본) / 4:5
- 실시간 미리보기 → [이미지 저장] [공유하기].
  - 공유: Web Share API(파일 공유)로 카카오톡 등에 바로 전달. 지원 안 되면 다운로드.
- 내보낸 기록(시작 월, 문구)을 저장해서 다음에 불러올 수 있게.

### 8.3 설정
- 공부방 이름, 하단 슬로건
- 운영 요일(기본 월~금)
- 요일반 시작점
- 공휴일: 연도별 내장 목록 보기, 수동 추가(임시공휴일), 무시 처리
- 휴원일·행사일 관리
- 기본 안내 문구 템플릿
- 경고 기준(앞섬/밀림 몇 회부터, 기본 2)
- 데이터 백업/복원(JSON 내보내기/가져오기), 초기 데이터 불러오기

## 9. 안내 달력 이미지 디자인
- 새로 디자인한다. 학부모(어린아이 부모)가 폰에서 확대 없이 읽을 수 있는 깔끔하고 따뜻한 느낌.
- 크기: 1080×1080(기본) 또는 1080×1350. 내보내기는 2배 해상도.
- 폰트: Pretendard를 프로젝트에 포함(woff2). 캡처 전에 `document.fonts.ready`를 기다린다.
- 구성(위→아래):
  1. 작은 공부방 이름 + 큰 제목("1월, 2월 수업 안내")
  2. 두 달 달력 — **나란히 배치를 기본으로 결정(2026-11-04)**. 위아래 배치도 선택할 수 있게 남겨 둔다.
     - 나란히: 1:1·4:5 모두 가능. 칸이 좁아 다른 수업월 라벨("12월 4주")과 "보강수업"은 두 줄로 쓴다.
     - 위아래: 정사각형에는 다 들어가지 않으므로 고르면 4:5로 자동 전환. 내용이 넘치면 화면에 경고.
     - 요일 헤더 일~토. 일요일·공휴일 빨강, 토요일 파랑.
     - 날짜 칸: 숫자 + 하단 색 띠에 라벨. 라벨 형식은 같은 달 수업월이면 "1주", 다른 수업월이면 "2월 1주".
     - 공휴일 칸: 공휴일 이름. 휴원 칸: 휴원 이름.
     - 토요 보강데이: "보강수업" 띠.
     - 6주짜리 달도 레이아웃이 깨지지 않게.
  3. 범례 한 줄: 1주·2주·3주·4주·보강수업 색
  4. 강조 안내 박스(연한 하이라이트 배경)
  5. 기본 안내 문구(작은 글씨, `*` 항목)
  6. 하단 슬로건
- 주차 색(기존 배치 유지):
  | 구분 | 색 |
  |---|---|
  | 1주 | #FFF0C2 (크림) |
  | 2주 | #AED581 (연두) |
  | 3주 | #80CBC4 (청록) |
  | 4주 | #9FA8DA (연보라) |
  | 보강수업 | #9C27B0 (자주, 흰 글씨) |
- 기본값:
  - 공부방 이름: 플레이팩토 망포꿈수학
  - 슬로건: 수학에 생각과 재미를 더하는 플레이팩토망포꿈수학
  - 기본 안내 문구 템플릿:
    ```
    * 보강 - 결석 시 주차 진도가 같은 수업이 있을 경우 해당 타임에 참여 가능합니다.
      (망포꿈수학은 4인 소수정예 수업을 유지하며, 해당 보강 친구가 있을 경우 5인까지 진행됩니다.)
      그 외의 경우 토요 보강데이(30분)로 진행되며 선생님과 상담 후 예약해 주세요.
      (당일 결석 보강 불가 / 보강은 월 1회로 제한됩니다)
    * 결제 - 랠리즈 앱을 통해 월말 일괄 발송됩니다. (수원페이, 랠리즈앱 카카오페이로 등록 가능 /
      매월 수업 첫 주까지 교육비를 마감하고 있습니다.) 항상 협조해 주시는 학부모님께 감사드립니다.
    ```

# 하린이 시간표 (7단계, 30~34단계)

공부방 앱 안에 딸 하린이(초4)의 평일 하교 후 시간표를 부모가 관리하는 화면을 둔다.
공부방 기능과 데이터가 섞이지 않게 표·화면·코드 폴더를 따로 둔다(`kid_*` 표, `src/engine/harin/`, `src/features/harin/`).

## 1. 목적과 범위
- 초4 딸 하린이의 평일(월~금) 하교 후 시간표를 부모(개발자와 원장님)가 관리한다.
- 하린이는 앱에 들어오지 않는다. 하린이 계정은 만들지 않는다. 하린이에게는 이미지로 저장·공유해서 보여 준다.
- 범위 밖(나중): 하린이 전용 보기, 숙제 퀘스트·캐릭터·리워드(시간표의 "숙제" 블록과 나중에 연결).

## 2. 위치와 분위기
- 할 일(홈) 화면 오른쪽 위 작은 **[하린]** 버튼 → 별도 화면. 주소 `/harin`(앱 안에서는 `#/harin`).
  - `/harin`은 따로 홈 화면에 추가할 수 있게 별도 HTML(`harin.html`)과 별도 앱 정보(`harin.webmanifest`, 이름 "하린이 시간표")를 쓴다. 열면 바로 `#/harin`으로 간다.
  - 로그인은 공부방 앱과 같다(로그아웃 상태면 로그인 화면).
- 공부방 앱과 다른 톤: 파스텔 색, 둥근 블록, 부드러운 그림자, 손글씨 느낌 글꼴 **Jua**(Google Fonts, OFL. 굵고 둥글어 작은 글씨도 잘 읽힘. Gaegu는 가늘어 작은 블록에서 흐림), 항목별 이모지.
  - Jua 파일은 앱에 넣어 둔다(`src/assets/fonts/Jua-Regular.woff2`). 이미지 저장 때 글꼴이 빠지지 않게 하기 위해서다. Jua에 없는 드문 글자는 Pretendard로 보인다.
- 하단 탭은 숨기고, 위에 [← 공부방] 버튼을 둔다. 다크모드는 고려하지 않는다(밝은 톤 고정).

## 3. 시간표 격자
- 열: 월~금. 행: 10분 단위.
- 입력 가능 범위: 13:30 ~ 23:00(`INPUT_START`, `INPUT_END`).
- 보이는 범위: 기본 14:00 ~ 23:00. 설정에서 시작·끝을 바꾼다(13:30까지 당길 수 있음, 30분 단위). 보이는 범위 밖에 블록(이동 포함)이 있으면 자동으로 넓혀 보여 준다(`visibleRange`).
- 블록 안 글자:
  - 30분 이상: "이모지 이름 / 시작~끝 / 장소(있으면)"
  - 10~20분: "이모지 이름 시작" 한 줄(넘치면 말줄임)
- 폰 세로: 요일 탭(한 요일씩). 가로·PC·태블릿: 5일 전체.
- [오늘] 목록: 오늘(주말이면 월요일) 일정을 시간순 텍스트로. 예: `3:00 🎹 피아노 (3:00~3:50) → 3:50 🚶 이동 20분 → 4:10 🍙 간식`.

## 4. 종류(카테고리)와 색
- 기본 종류(마이그레이션이 넣음):

| 종류 | 색 | 이모지 | 기본 길이 | 표시 |
|---|---|---|---|---|
| 학원 | 학원마다 다름(종류 색은 대체용) | 🏫 | 50분 | `is_activity` |
| 이동 | 연회색 빗금 | 🚶 | - | `is_travel` |
| 식사 | 주황 | 🍚 | 30분 | |
| 휴식 | 연두 | 🧸 | 20분 | |
| 숙제 | 하늘 | ✏️ | 50분 | |
| 기타 | 연보라 | ⭐ | 50분 | |

- 설정에서 종류 추가, 이름·색·이모지·기본 길이 변경.
- 이동 종류와 학원 종류는 삭제할 수 없다. 블록에서 쓰는 종류도 삭제할 수 없다(먼저 블록을 옮기거나 지움).

## 5. 학원(수업) 목록
- 한 번 등록해 두고 시간표에 놓는다: 이름, 이모지, 색, 장소(선택), 메모(선택), 이동 시간(분, 기본 20), "집에서 듣는 수업"(체크하면 이동 없음, 예: 화상영어).
- 이동 시간·집 수업 여부를 바꾸면 모든 시간표의 이동 블록이 다시 계산된다(이동은 저장하지 않으므로 저절로).
- 시간표에서 쓰는 학원은 삭제할 수 없다.

## 6. 이동 블록 자동 생성(`buildTravelBlocks`)
- 이동은 저장하지 않고 학원 블록 + 학원 기본값 + 블록별 override로 매번 계산한다.
- 학원 블록 앞뒤에 이동 블록(학원의 이동 시간)이 붙는다. 집 수업은 붙지 않는다.
- **연속된 학원**: 같은 요일에 학원 A 다음 학원 B가 오고, 그 사이에 다른 블록이 없고, 사이 간격이 (A 기본 이동 + B 기본 이동)보다 짧으면 집에 들르지 않고 바로 가는 것으로 보고 이동 하나만 붙인다. A 끝에서 시작, 길이는 B의 앞 이동(override 포함). 간격이 그보다 길면 집에 다녀오는 것으로 보고 따로 붙인다.
- 한쪽만 집 수업이면 연속으로 보지 않는다(집 수업 쪽은 이동 없음, 다른 쪽은 자기 이동).
- 블록별로 다르게: 이동 블록을 탭해 길이 변경 또는 "이번만 이동 없음"(0분). 그 학원 블록의 `travel_before_override`/`travel_after_override`에 저장하고 학원 기본값은 그대로. 연속 이동은 B의 앞 이동 값.
- 경고(막지는 않음): 이동이 다른 블록과 겹침, 입력 범위(13:30~23:00) 밖으로 나감.
- 이동 블록은 직접 옮기지 않는다(학원을 옮기면 따라감).

## 7. 편집(편성 시뮬레이터 방식 재사용)
- PC: 마우스로 5px 이상 끌면 이동. 폰: 0.25초 길게 눌러 끌기. 탭 → 칸 탭으로도 이동. 10분 칸에 붙는다.
- 같은 요일에서 블록끼리(이동 제외) 겹치면 놓을 수 없다. 입력 범위 밖도 불가(`canPlaceKid`).
- 길이 조절: 블록 아래 끝 손잡이를 끌어서(10분 단위). 블록 탭 → 편집 창에서 시작·끝 시간 선택으로도 가능.
- 빈 칸 탭 → 새 블록: 종류 선택 → 학원이면 학원 목록에서 고르기, 그 외는 이름 입력(비우면 종류 이름). 기본 길이는 종류의 기본 길이.
- 블록 복사 → 다른 요일들에 붙여넣기(요일 여러 개 선택). 겹치는 요일은 건너뛰고 알려 준다.
- 되돌리기/다시 실행(이번 접속 중, 최대 50개, PC Ctrl+Z/Ctrl+Y), 모든 조작은 바로 자동 저장.

## 8. 시간표 버전
- 여러 개 만들 수 있다(예: "2학기", "겨울방학"). 이름·메모 변경, 복제(블록까지 복사), 삭제(확인).
- 하나만 "대표"(★). `/harin`을 열면 대표 시간표가 보인다. 위쪽 드롭다운으로 다른 버전을 열어 편집.
- 처음 열면(시간표 없음) [시간표 만들기]로 "2학기"를 대표로 만든다.
- 대표를 지우면 남은 것 중 맨 위가 대표가 된다.

## 9. 이미지로 저장·공유
- [이미지] → 비율 선택(폰 세로 9:16 / 출력용 가로) → [저장] 또는 [공유]. 지금 보고 있는 시간표(5일 전체, 보이는 범위)를 PNG로. 안내 달력 만들기의 변환·공유 코드(`features/export/imageExport.ts`)를 쓴다.
- 이미지 위: "하린이 시간표 · 버전 이름", 아래: 범례(종류별 색·이모지, 쓴 학원).

## 10. 데이터와 보안
- 표(모두 RLS + `private.is_member()`, 백업 내보내기·복원에 포함):
  - `kid_timetables(id, name, memo, is_main, sort, created_at, updated_at, updated_by)` — `is_main`은 하나만 true(부분 유니크 인덱스).
  - `kid_categories(id, name, color, emoji, is_travel, is_activity, default_minutes, sort)`
  - `kid_activities(id, name, emoji, color, place, memo, travel_minutes default 20, is_home default false, sort)`
  - `kid_blocks(id, timetable_id, weekday 1~5, start_time 'HH:MM', end_time 'HH:MM', category_id, activity_id null, title, memo, travel_before_override null, travel_after_override null)`
  - 이동 블록은 저장하지 않는다.
- 설정: `settings.data.harin = { viewStart, viewEnd }`.
- 하린이 이름 외 개인정보는 저장하지 않는다(학원 장소는 학원 이름·동네 정도로).

## 11. 순수 함수(`src/engine/harin/`)
- `buildTravelBlocks(blocks, activities)` — 6장.
- `canPlaceKid(blocks, block, weekday, start, end?)` — 겹침 불가, 13:30~23:00 밖 불가, 10분 단위.
- `dayAgenda(blocks, activities, categories, weekday)` / `agendaText` — [오늘] 목록.
- `visibleRange`, 블록 글자 모양 판단.
- 편성 시뮬레이터와 공유하는 시간 계산(겹침, 10분 맞춤, 잡은 위치 계산)은 `src/engine/timeRange.ts`.

## 12. 작업 순서
- 30단계: 이 문서, CLAUDE.md, 마이그레이션 + 기본 종류, 11장 순수 함수와 테스트.
- 31단계: `/harin` 화면(대표 시간표, 격자·블록 글자, 색·이모지, 폰 요일 탭/PC 전체, [오늘]).
- 32단계: 편집(새 블록, 탭·드래그 이동, 끝 끌어 길이 조절, 복사→여러 요일, 되돌리기, 이동 override).
- 33단계: 학원 목록, 종류 관리, 보이는 시간 범위, 시간표 버전.
- 34단계: 이미지 저장·공유, 홈 [하린] 버튼, 마무리 점검.

## 13. 정해서 진행한 것(확인 필요)
1. 학원 종류·기본 길이를 이름으로 구분하지 않으려고 `kid_categories`에 `is_activity`, `default_minutes` 칸을 더했다. 학원 목록 순서용 `kid_activities.sort`도 더했다.
2. 연속 학원 판단(6장): 사이에 다른 블록이 없고 간격 < (A 기본 이동 + B 기본 이동). 블록별 override는 판단에 쓰지 않고 길이만 바꾼다("이번만 이동 없음"이면 사이 이동이 없어짐).
3. 이동이 23:00 뒤로 나가도 "입력 범위 밖" 경고.
4. 블록에서 쓰는 학원·종류는 삭제 불가.
5. 이미지 비율: 세로 1080×1920(9:16), 가로 1600×1130(A4 가로 비율).

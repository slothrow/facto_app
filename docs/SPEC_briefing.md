# 학사운영 앱 상세 기획서 (3단계: 교육과정 진도 + 수업 후 브리핑)

> docs/SPEC.md(회차 엔진), docs/SPEC_students.md(반·학생·결석)에 이어지는 문서.
> 이번 범위: 반별 교육과정 진도 자동 계산, 코드별 브리핑 문구 저장소, 수업 후 브리핑 화면(아이별 카톡 공유), 보낸 기록과 개인 진도 자동 누적.
> 범위 밖: 사진·동영상(갤러리에서 직접 전송), 아이별 추가 코멘트, 반 공통 공지 문구, 체험수업 아이 브리핑, 보강 매칭.

## 1. 현재 업무 방식과 목표
- 지금: 수업이 끝나면 그 반의 오늘 수업 코드(예: P8-1)에 맞는 브리핑 문구를 카톡에 저장해 둔 글에서 찾아 복사 → 카톡에서 아이 이름("홍길동 7세")을 검색 → 붙여넣기 → 전송. 사진·영상은 그 뒤에 갤러리에서 따로 보낸다.
- 목표: 앱에서 시간대 반 버튼만 누르면 오늘 코드와 문구가 바로 뜨고, 아이별 [보내기] → 카톡 대화방 선택 → 전송으로 끝난다. 보낸 기록과 진도는 자동으로 쌓인다.

## 2. 교육과정 구조
- 단계 6개, 순서 고정: **베이직 → K → P → A → B → S**
- 단계별 대상(기본 매칭): 베이직=5세, K=6세, P=7세, A=초1, B=초2, S=초3
- 단계마다 단원 12개. 한 수업월에 단원 1개.
- 한 단원은 4주 구성 = 회차 엔진의 수업월 1~4주와 1:1 대응.
- **수업 코드 = 단계 코드 + 단원 번호 + "-" + 주차.** 예: `P1-1` = P단계 1단원 1주차.
- 단원 12 다음은 자동으로 다음 단계 단원 1. 예: P12 → A1. S12 다음은 "과정 완료"(코드 없음).
- 단계 코드(접두어)는 설정에서 바꿀 수 있게 한다. 기본값: K=`K`, P=`P`, A=`A`, B=`B`, S=`S`.

### 2.1 베이직 단계 (2026-11-06 결정)
- 베이직은 12단원으로 정해진 과정이 아니다. 수업 내용이 그때그때 달라서 **선생님이 2주쯤 전에 날짜별로 미리 정한다.**
- 그래서 베이직 반은 단원·코드를 자동 계산하지 않는다. 대신 **베이직 수업 계획** `basic_lesson_plans(class_id, date, title, text)`에 날짜별 수업 제목과 브리핑 문구를 미리 적어 두고, 브리핑 화면에서 그 날짜의 계획을 쓴다.
- 표시 이름은 `베이직`(한글). 브리핑 기록의 코드는 `베이직 · <제목>`으로 남긴다.
- 반의 진도 기준점을 "베이직"(단원 없음)으로 두면 다음 기준점 전까지 계속 베이직이다. 베이직을 마치면 그 수업월에 `K 1단원` 기준점을 추가한다(베이직 다음 단계로 자동으로 넘어가지 않는다).
- 문구 관리 화면의 베이직 탭: 베이직 반의 앞으로 수업 날짜(약 6주) 목록 → 날짜마다 제목·문구 입력, 채워진/빈 날짜 표시.

## 3. 반별 진도 계산

### 3.1 진도 기준점
- 반마다 "어느 수업월에 어느 단계 몇 단원을 했는지"를 기준점으로 저장: `class_progress_anchors(class_id, course_month, stage, unit)`
- 학년도나 달력과는 무관하다. 반에서 정한 기준점부터 수업월마다 단원이 1씩 올라간다.
- 기준점에는 주차(`unit_week`, 1~4, 기본 1)도 있다. "그 수업월 1회차가 몇 주차 수업인지"이다. 예: 2027-01 수업월 = B1-3 → 1~4회 B1-3, B1-4, B2-1, B2-2, 다음 수업월 1회 B2-3 (2026-11-10 결정).
- 기준점은 여러 개 둘 수 있다. 어떤 수업월 M의 진도는 M 이전(또는 같은) 기준점 중 가장 최근 것에서 계산한다. 실제와 다르게 흘러가면 그 수업월에 기준점을 하나 더 추가해서 고친다.

### 3.2 계산 규칙 (순수 함수, src/engine/curriculum.ts)
```
codeFor(class, date):
  1) 회차 엔진으로 그 반 요일의 date 회차를 구한다 → (courseMonth, weekNo). 회차가 없으면(공휴일·휴원·비움) 코드 없음.
  2) courseMonth 이하인 가장 최근 기준점 A를 찾는다. 없으면 "진도 미설정".
  2-1) A가 베이직이면 "베이직"(그 날짜의 베이직 수업 계획을 쓴다). 코드 없음.
  3) n = (A.unit - 1) * 4 + (A.unit_week - 1) + 수업월 차이(courseMonth - A.course_month) * 4 + (weekNo - 1)   // 단계 처음부터 몇 번째 수업
     stageIndex = index(A.stage) + floor(n / 48), unit = floor((n % 48) / 4) + 1, week = n % 4 + 1
     stageIndex가 S를 넘으면 "과정 완료". (unit_week = 1이면 예전 규칙과 같다: week = weekNo)
  4) code = prefix(stage) + unit + "-" + week
```
- **반드시 달력월이 아니라 수업월 기준**으로 계산한다(앞섬·밀림이 있는 요일 때문).

### 3.3 테스트 기준
SPEC.md 7.2의 2027년 1~2월 회차 결과(휴원 없는 기준 입력)를 사용한다.
- 화 반, 기준점 2026-12 = P8
  - 2027-01-05(화) = 1월 수업월 3주 → `P9-3`
  - 2027-02-23(화) = 3월 수업월 1주 → `P11-1`
- 금 반, 기준점 2026-12 = P8
  - 2027-01-08(금) = 12월 수업월 4주 → `P8-4` (달력은 1월이지만 수업월은 12월)
  - 2027-01-15(금) = 1월 수업월 1주 → `P9-1`
- 기준점 2027-01 = P12 → 2027-02 수업월 = `A1-x`
- 기준점 2027-01 = S12 → 2027-02 수업월 = 과정 완료
- 기준점 2개: 2026-12 = P8, 2027-03 = P5 → 2027-02 수업월 `P10`, 2027-03 수업월 `P5`, 2027-04 수업월 `P6`
- 공휴일(2027-02-09 화) → 코드 없음

### 3.4 반 진도 화면
- 반 상세에 "진도" 영역: 이번 수업월 단계·단원(예: "P9 · 1월 수업월"), 기준점 목록, [기준점 추가/수정].
- 기준점을 넣을 때 단계 기본값은 반 학년의 기본 매칭(2장)으로 제안. 반 학년과 단계가 다르면 경고만 표시.
- 반 목록에 각 반의 현재 단계·단원 표시.

### 3.5 반 진도 일괄 입력
- 설정 또는 반 목록의 [진도 일괄 입력]: CSV/엑셀 붙여넣기 → 미리보기 → 저장.
- 열: `요일, 시작시간, 수업월, 단계, 단원` (예: `화,16:30,2026-12,P,8`)
- 그 밖의 열(예: 반학년 참고용)은 무시한다.
- 요일+시작시간으로 운영 중인 반을 찾는다. 못 찾으면 그 줄을 오류로 표시하고 건너뛴다.
- [양식 내려받기]: 운영 중인 반 목록이 미리 채워진 CSV를 만들어 준다(단계·단원 칸은 빈칸).

## 4. 브리핑 문구 저장소
- `briefing_texts(code pk, text, updated_at, updated_by)`. 코드당 문구 1개. 아이 이름은 들어가지 않는다.
- 화면: 단계별 탭 → 단원 × 주차 격자(12 × 4)로 채워진 칸/빈 칸 표시, 단계별 진행률(예: "P 31/48"). 칸을 누르면 문구 보기·수정.
- **일괄 가져오기**: CSV/엑셀 붙여넣기(`코드, 문구`). 문구 안 줄바꿈 유지. 이미 있는 코드는 "덮어쓰기 / 건너뛰기" 선택. 코드 형식이 맞지 않는 줄은 오류로 표시.
- 브리핑 화면에서 문구가 없으면 그 자리에서 작성 → 저장소에 저장.

## 5. 수업 후 브리핑 화면

### 5.1 흐름
1. 하단 탭 **[브리핑]** (첫 번째 탭으로).
2. 상단: 날짜(기본 오늘, 변경 가능). 그 날짜에 수업이 있는 반을 시작 시간 버튼으로 나열: `2:30` `3:30` `4:30` `5:30`. 각 버튼에 진행 표시(예: `3/4`).
   - 기본 선택: 지금 시각 기준으로 가장 최근에 끝난 반(없으면 첫 반).
   - 공휴일·휴원 등으로 수업이 없는 날은 "오늘은 수업이 없습니다".
3. 반을 누르면:
   - 오늘 코드(큰 글씨)와 브리핑 문구 전체.
   - 문구 [수정] → 저장소 문구가 바뀐다(다음에도 적용).
   - 진도 미설정이면 "이 반의 진도를 먼저 설정하세요" + 반 진도 화면 바로가기.
4. 아이 목록: 그날 기준 반 명단(SPEC_students 3.3)에서 그날 결석한 아이를 뺀다. 결석 아이는 맨 아래 회색으로 "결석"만 표시.
   - [+ 아이 추가]: 다른 반 아이를 그날 이 반 목록에 임시로 추가(보강 온 경우). 이름 검색으로.
5. 아이마다 **[보내기]** 버튼. 보낸 아이는 ✓와 보낸 시각, 다시 누르면 "보냄 취소" 확인.

### 5.2 [보내기] 동작
1. 그 아이의 **카톡 검색어**(학생 정보의 새 항목, 기본값 = 이름)를 클립보드에 복사.
2. `navigator.share({ text: 브리핑 문구 })`로 공유 창을 연다(텍스트만, 파일 없음).
3. 공유가 완료되면(Promise resolve) 그 아이를 "보냄"으로 기록. 취소(AbortError)면 기록하지 않음.
4. 공유 창 안내 토스트: "카톡에서 검색창을 누르고 키보드의 붙여넣기 추천을 탭하세요".
- 클립보드 복사와 공유를 한 번의 탭으로 처리하는 것이 안드로이드 크롬에서 되는지 실제 기기로 확인. 안 되면 버튼을 [이름 복사] [공유] 두 단계로 나눈다.
- Web Share 미지원(PC 등): 문구를 클립보드에 복사하고 "복사됨" 표시 후 보냄으로 기록할지 확인.

### 5.3 형제자매
- 따로 보낸다. 같은 날 형제가 있으면 목록에서 이름 옆에 "형제" 표시만.

## 6. 자동 기록과 진도

### 6.1 보낸 기록
- `briefings(id, date, class_id, student_id, code, text_snapshot, shared_at, shared_by)`, 고유키 (date, class_id, student_id).
- text_snapshot: 실제로 보낸 문구 그대로(나중에 저장소 문구가 바뀌어도 기록은 유지).

### 6.2 개인 진도 (계산값, 저장하지 않음)
- 이수: 그 아이가 반에 배정돼 있던 날 중 회차가 있고 결석하지 않은 날의 코드.
- [+ 아이 추가]로 다른 반에서 브리핑을 받은 날도 이수로 친다(briefings 기록 기준).
- 미이수: 배정돼 있던 날인데 결석한 날의 코드 → 다음 단계 보강 기능의 입력.

### 6.3 화면
- 학생 카드에 **"배운 내용"** 섹션: 날짜 · 코드 · 브리핑 보냄 여부(✓). 결석 날은 "결석(미이수)" 표시.
- 반 상세에 이번 수업월 브리핑 현황: 날짜별 "4/4 보냄".

## 7. 학생 정보 추가 항목
- `students.kakao_search text null` — 카톡 대화방 검색어. 비어 있으면 이름 사용.
- 학생 카드와 일괄 가져오기에 이 열 추가(`카톡검색어`).

하단 탭: **브리핑 / 회차 계획 / 반·학생 / 달력 만들기 / 설정**

## 10. 확인 필요 사항
- ~~베이직 단계의 코드 접두어~~ → 2.1로 결정(단원 없이 날짜별 수업 계획).

## 11. 원장님용 브리핑 사용 안내 (폰)
1. 수업이 끝나면 **[브리핑]** 탭 → 방금 끝난 반이 골라져 있어요(다른 반은 위 시간 버튼).
2. 오늘 코드·문구를 확인하고 아이 옆 **[보내기]** → 공유 창에서 **카카오톡** 선택.
3. 카톡 검색창을 누르고 키보드 위 **붙여넣기 추천(아이 이름)** 탭 → 대화방 선택 → 전송. 앱에 ✓가 남아요.
4. 문구가 없거나 고칠 땐 [지금 작성]/[문구 수정](다음에도 그대로 쓰여요). 베이직 반은 [문구 관리 → 베이직]에 날짜별로 미리 적어요.
5. 결석한 아이는 맨 아래 회색, 보강 온 아이는 [+ 아이 추가]. 잘못 찍힌 ✓는 눌러서 취소해요.
